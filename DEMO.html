📦 Installation

For Safari on macOS

  1. Enable Developer Mode in Safari:
    • Go to Safari → Preferences → Advanced
    • Check "Show Develop menu in menu bar"
  2. Load the Extension:
    • Go to Develop → Allow Unsigned Extensions
    • Go to Safari → Preferences → Extensions
    • Click "+" and select the extension folder

💡 How It Works

The extension uses modern web technologies to enhance your GitHub experience:

  • Content Scripts: Inject decorations directly into GitHub pages
  • CSS Animations: Smooth, GPU-accelerated snowfall effects
  • DOM Manipulation: Intelligently decorates contribution graphs and headers
  • Persistent Storage: Remembers your preferences across sessions
